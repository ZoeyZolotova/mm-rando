# Majora's Mask Randomizer SEQS YAML File
#   This YAML file determines which sequences from the in-game areas can be randomized when randomizing music is enabled.
#   If a sequence is not in this file, it will not be randomized. Each entry used by the file, and its corresponding fields
#   is explained below.
#
# Sequence Name:
#   The main key value for an entry (e.g. "mm-terminafield") is the name of the sequence. If you wish to change the name of
#   the sequence in-game, please use the display name field — this field (sequence name) is not what is displayed in-game.
#   Users should not change this — the randomizer has some hardcoded reliance on the entry's key.
#
# Display Name:
#   The display name is the name to be displayed in-game.
#   Users may change this.
#
# Music Groups:
#   The music groups is what areas the sequence can randomize into, for the full list of groups look at MusicGroups.cs
#   Both strings and ints are allowed as long as the values are valid in MusicGroups.cs
#   Users may change this.
#
# Instrument Set:
#   The ID (index) of the instrument bank in the AudioBank index. This determines which instrument bank is used by the vanilla sequence.
#   Users should not change this.
#
# Sequence ID:
#   The ID (index) of the sequence in the AudioSeq index. This determines which sequences can be replaced by music.
#   Users should not change this.
#
# Song Type:
#  The sequence's type. This is used to determine what default music group list will be used if the music groups field is empty.
#  Users should not change this.
#
# No Recycle:
#   A boolean that determines if vanila sequences will be used during music randomization.
#   False means vanilla sequences will be used during randomization, and True means they will not be used.
#   Users may change this.
